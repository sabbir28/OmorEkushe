Core Engine (`src/core/`)

  • layout.cpp / layout.h

    Parses layout XML definitions, builds in-memory character mappings (`KeyMap`), and resolves modifier key states (Normal, Shift, AltGr, Conjuncts/Juk).

  • layout_discovery.cpp

    Scans `data/Layouts/` relative path for available `.xml` layout definition files at runtime and populates available layout choices.

  • spelling_checker.cpp

    Fast C++ dictionary lookup engine for Bengali word validation and real-time spell suggestions.

  • net_client.cpp

    Socket networking client allowing remote layout updates and IPC messaging between modules.

Win32 Platform (`src/platform/windows/`)

  • main_window.cpp

    Manages top acrylic glass overlay window, transparency sliders, background rendering, and Win32 event dispatching loop.

  • native_input.cpp

    Installs low-level system keyboard hook (`SetWindowsHookExW(WH_KEYBOARD_LL)`) to capture physical keystrokes system-wide and inject unicode characters (`SendInput`).

  • registration_dialog.cpp

    Win32 registration dialog window and registry configuration loader/saver (`HKCU\Software\OmorEkushe`).

  • main_window_tray.cpp

    Creates system notification area icon (`NOTIFYICONDATA`), handles double-click restore, and right-click pop-up menu.

Installer Setup (`Installer/`)

  • InstallerLogic.cpp

    Self-extracting Win32 installer engine. Iterates over embedded binary payload array and writes target `bin/` and `data/` files to destination disk directory.

  • bundler.cpp

    Build tool executed during compilation to compress executables (`OmorEkushe.exe`, `NetClient.exe`) and layout XML maps into C++ byte arrays inside `Installer.exe`.

Layout Editor (`LayoutEditor/`)

  • main.cpp

    Initializes GLFW OpenGL window context and sets up Dear ImGui render loop.

  • LayoutEditor.cpp

    Graphical keymap designer UI for visual key assignment, XML layout creation, and live testing.
