1. Low-Level Hook Interception

keyboard_hook_service.cpp installs a low-level global Windows hook using SetWindowsHookExW. Intercepted key events are evaluated against the per-window layout context and modifier state. If Bangla mode is active, native input is consumed and directed into the active engine.

2. Dual Typing Translation Engines

In Phonetic Mode (F12), keystrokes pass through a Trie-based Avro parser that handles vowel-kar conversions, conjunct resolution, and emits dynamic backspaces for seamless editing. In Fixed Mode (Ctrl+Alt+B), layout.cpp performs O(1) keymap lookups to inject UTF-16 glyphs via SendInput.
