1. Interception & Hook Layer

`native_input.cpp` installs a low-level global Windows hook using `SetWindowsHookExW`. When Bangla mode is active, intercepted Virtual Keycodes (VK) are blocked from standard OS processing and forwarded to the layout mapper.

2. XML Mapper & Output

`layout.cpp` performs an $O(1)$ lookup in the active layout map table for the corresponding UTF-16 character or conjunctive sequence, then emits keystrokes using Win32 API `SendInput` with `KEYEVENTF_UNICODE`.
