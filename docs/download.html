Installation Walkthrough

1
Run Setup Installer

Execute `OmorEkushe-Setup.exe`. The embedded Win32 setup unpacks application binaries and XML layout files to your system directory.

2
Control Bar & System Tray

Omor Ekushe launches directly to your top display bar and minimizes cleanly into the Windows System Tray notification area.

3
Toggle Bangla Hotkey

Press Ctrl + Alt + B in any document, browser, or editor to switch between Bangla & English typing.
