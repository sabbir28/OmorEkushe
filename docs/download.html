Quick-Start Walkthrough

1
Run Setup

Run OmorEkushe-Setup.exe. Inno Setup safely installs application binaries, registers shortcuts, and copies layout files.

2
Overlay & Tray

The floating control bar appears at the top. Minimize it to the system tray anytime by pressing Esc.

3
Toggle & Type

Press F12 for Avro Phonetic typing, or Ctrl+Alt+B to cycle fixed layouts (Bijoy/Unijoy).
