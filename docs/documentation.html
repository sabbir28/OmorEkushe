Default Hotkeys & Shortcuts

Win32 Hook
Action Shortcut Keycap Behavior
Toggle Layout Ctrl + Alt + B Instantly switches between Bangla and English mode.

Restore Overlay Double Click Tray Icon Restores top acrylic control window overlay.

Registry Configuration & Cleanup

HKCU Registry

Omor Ekushe stores active layout choices and overlay opacity preferences under Windows Registry Current User keys:

HKEY_CURRENT_USER\Software\OmorEkushe

To reset all settings to clean factory defaults or clean registry entries, run the batch script command:

remove_registry.bat 
reg delete "HKCU\Software\OmorEkushe" /f

Building from Source with CMake

Follow these instructions to compile Omor Ekushe on Visual Studio (MSVC) or MinGW-w64 toolchains.

PowerShell / Visual Studio Developer Prompt 
# 1. Clone Omor Ekushe repository
git clone https://github.com/sabbir28/OmorEkushe.git
cd OmorEkushe

# 2. Generate CMake build configuration for Visual Studio (x64)
cmake -B build -A x64

# 3. Build Release executable
cmake --build build --config Release

# Output binary generated in: build/bin/Release/OmorEkushe.exe
Bash / MinGW Terminal 
# 1. Generate MinGW Makefiles
cmake -B build -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=Release

# 2. Build executable target
cmake --build build

# Output binary generated in: build/bin/OmorEkushe.exe
Build Dear ImGui Graphical Keymap Designer 
# Enable Layout Editor sub-module build flag
cmake -B build -DBIJOY_BUILD_LAYOUT_EDITOR=ON
cmake --build build --config Release

# Output binary target: build/bin/LayoutEditor.exe

Source Tree Modules Breakdown

Detailed breakdown of repository modules, source files, and build configuration targets.

Core Engine (`src/core/`)
  • layout.cpp / layout.h: XML keymap parser and in-memory key mapping dictionary.
  • layout_discovery.cpp: Dynamically scans data/Layouts/ directory for XML layouts.
  • spelling_checker.cpp: Native C++ Bengali spellchecker & dictionary lookup core.
  • net_client.cpp: Lightweight IPC socket client module for remote layout sync.
Win32 Integration (`src/platform/windows/`)
  • main_window.cpp: Top acrylic control bar overlay & Win32 window message loop.
  • native_input.cpp: Low-level system keyboard hook (WH_KEYBOARD_LL).
  • registration_dialog.cpp: Win32 registry settings UI and persistence.
  • main_window_tray.cpp: System tray notification icon & context menu.
Installer Sub-Module (`Installer/`)
  • InstallerLogic.cpp: Unpacks embedded binary payload array to target disk directory.
  • bundler.cpp: Build tool that embeds application binaries into single setup installer.
GitHub Workflows (`.github/workflows/`)
  • build.yml: CI build matrix compiling MSVC & MinGW targets.
  • release.yml: Automated GitHub Release publisher publishing versioned binaries.
  • jekyll-gh-pages.yml: Automated GitHub Pages documentation deployment pipeline.
