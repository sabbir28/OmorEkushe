Default Hotkeys & Shortcuts

Action Shortcut Description
Toggle Layout Ctrl + Alt + B Instantly switches between Bangla and English mode.
Minimize to Tray Esc or _ button Hides top control bar to system notification tray.
Restore Bar Double Click Tray Icon Restores top acrylic control overlay window.
Exit Application Right-Click Tray → Exit Terminates background hook service and exits app.

Registry Cleanup & Scripts

Omor Ekushe stores active layout choices and overlay opacity preferences under current user Windows Registry keys:

HKEY_CURRENT_USER\Software\OmorEkushe

To reset all settings to clean factory defaults or uninstall, run the included batch script in project root:

remove_registry.bat 
reg delete "HKCU\Software\OmorEkushe" /f

Building from Source with CMake

Follow these instructions to compile Omor Ekushe on Visual Studio (MSVC) or MinGW-w64.

PowerShell / Command Prompt 
# 1. Clone repository
git clone https://github.com/sabbir28/OmorEkushe.git
cd OmorEkushe

# 2. Generate build files for Visual Studio (x64)
cmake -B build -A x64

# 3. Build Release executable
cmake --build build --config Release

# Output binary generated in: build/bin/Release/OmorEkushe.exe
Bash / MinGW Terminal 
# 1. Generate MinGW Makefiles
cmake -B build -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=Release

# 2. Build executable
cmake --build build

# Output binary generated in: build/bin/OmorEkushe.exe
Build ImGui Graphical Layout Editor 
# Enable Layout Editor target
cmake -B build -DBIJOY_BUILD_LAYOUT_EDITOR=ON
cmake --build build --config Release

# Output binary: build/bin/LayoutEditor.exe

Codebase Architecture & File Structure

Overview of project modules, source tree organization, build targets, and CI pipelines.

Core Engine (`src/core/`)
  • layout.cpp / layout.h: XML keymap parser and in-memory keyboard mapping dictionary.
  • layout_discovery.cpp: Dynamically scans data/Layouts/ directory for XML layouts.
  • spelling_checker.cpp: Native Bengali spellchecking and dictionary lookup engine.
  • net_client.cpp: Lightweight IPC / socket networking module for remote layout sync.
Win32 Platform (`src/platform/windows/`)
  • main_window.cpp: Top acrylic control bar overlay & Win32 message loop handler.
  • native_input.cpp: Low-level keyboard hook (WH_KEYBOARD_LL) for key interception.
  • registration_dialog.cpp: Win32 registration UI dialog and setting persistence.
  • main_window_tray.cpp: System tray notification icon and right-click context menu.
Installer Sub-Module (`Installer/`)
  • InstallerLogic.cpp: Unpacks embedded bin/ and data/ payload to target installation folder.
  • bundler.cpp: Build tool that embeds application binaries and layout XMLs into single OmorEkushe-Setup.exe.
Workflows & Configs (`.github/`, `data/`)
  • data/Layouts/*.xml: XML definitions for Bijoy, Unijoy, and National keymaps.
  • .github/workflows/build.yml: CI build matrix verifying MSVC & MinGW targets.
  • .github/workflows/release.yml: Automated release workflow publishing binaries on code push.
  • .github/workflows/jekyll-gh-pages.yml: Automated GitHub Pages website deployment workflow.
