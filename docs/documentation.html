Options Dialog & Registry

HKCU Registry

Omor Ekushe features a full native settings dialog allowing live customization of:

  • Overlay Opacity: Interactive slider from 20% to 100% opacity with instant visual alpha preview.
  • Auto-Start with Windows: Automatically launches on login via HKCU\Software\Microsoft\Windows\CurrentVersion\Run.
  • Custom Hotkey Modifiers: Pick your own key bindings for Layout Switching and Phonetic toggle.
HKEY_CURRENT_USER\Software\OmorEkushe
Reset to Defaults (remove_registry.bat) 
reg delete "HKCU\Software\OmorEkushe" /f

Building from Source (Pure C++17)

Developers only compile pure C++ binaries locally. No installer software or bundlers are required on your device!

PowerShell / Developer Command Prompt 
# 1. Clone Omor Ekushe
git clone https://github.com/sabbir28/OmorEkushe.git
cd OmorEkushe

# 2. Configure build with CMake
cmake -B out/build/x64-Release -DCMAKE_BUILD_TYPE=Release

# 3. Compile binaries
cmake --build out/build/x64-Release --config Release

# Output binary placed in: build/bin/OmorEkushe.exe
Bash / MinGW Terminal 
# 1. Generate MinGW Makefiles
cmake -B build -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=Release

# 2. Compile executable
cmake --build build

# Output binary placed in: build/bin/OmorEkushe.exe
Run Avro Phonetic Test Suite 
# Run automated phonetic suite verifying 410+ transliteration test cases
.\build\bin\PhoneticTests.exe

Source Code Modular Architecture

Overview of C++ source files, Inno Setup scripts, and GitHub Actions CI pipelines.

Core Engines (`src/core/`)
  • phonetic_engine.cpp: Avro transliteration coordinator & dynamic backspacing diff engine.
  • phonetic_parser.cpp: Phonetic Trie parser, consonant clusters, and Kar transformations.
  • startup_options.cpp: Registry persistence for opacity, auto-start, and hotkeys.
  • layout.cpp / layout.h: XML keymap parser and in-memory lookup table.
  • layout_discovery.cpp: Scans data/Layouts/ for XML layouts.
  • keyboard_hook_service.cpp: Low-level keyboard hook (WH_KEYBOARD_LL).
Win32 Native UI (`src/platform/windows/`)
  • main_window.cpp: Top acrylic control bar overlay & Win32 message loop.
  • options_dialog.cpp: Full Options dialog with opacity slider & shortcut inputs.
  • main_window_tray.cpp: System tray notification icon & context menus.
  • splash_screen.cpp: Native lightweight startup splash screen.
Inno Setup Packaging (`setup/`)
  • OmorEkushe.iss: Standard Inno Setup definition script.
  • CloseApplications: Detects and gracefully closes running instances during upgrade.
  • /VERYSILENT: CLI silent deployment switch for unattended upgrades.
GitHub Workflows (`.github/workflows/`)
  • release.yml: Builds Release binaries, compiles Inno Setup installer via ISCC, packages portable ZIP, and publishes to GitHub Releases.
  • build.yml: Matrix CI compiling MSVC and MinGW-w64 on every push.
  • jekyll-gh-pages.yml: Deploys documentation site to GitHub Pages automatically.
