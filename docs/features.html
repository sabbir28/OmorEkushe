Low-Level Hook Service

WH_KEYBOARD_LL

Omor Ekushe intercepts hardware keyboard events directly at the Windows kernel message layer using `SetWindowsHookExW(WH_KEYBOARD_LL, ...)`. This delivers:

  • Zero input latency across all Win32, UWP, WPF, and Chromium applications.
  • Clean passthrough for system hotkeys like Alt+Tab, Win key, and Ctrl+C/V.
  • Precise keycode translation into UTF-16 Bengali glyphs (`SendInput`).

Integrated Spelling Checker

Sub-module: SpellingChecker

Built-in C++ spelling verification sub-module located in `SpellingChecker/` engineered for high-performance Bengali word verification.

  • High-speed dictionary lookups for standard Bengali vocabulary.
  • Phonetic distance matching for real-time word suggestion candidates.
  • Extendable custom dictionary file support.

Graphical Layout Editor

Sub-module: LayoutEditor

A standalone graphical keymap designer built with GLFW, OpenGL 3.3, and Dear ImGui GUI framework.

  • Visual key mapping matrix display for all standard virtual keys.
  • Real-time Unicode preview of Bengali character combinations.
  • One-click export to Omor Ekushe standard XML keymap format.

Cloud NetClient Sync

Sub-module: NetClient

Network client sub-module in `NetClient/` enabling cloud layout synchronization and automatic layout updates.

  • Online checking for layout map & application updates.
  • Download community layout XML files directly into `data/Layouts/`.

Custom XML Layout Map Syntax

Learn how to construct custom layout keymap files for Omor Ekushe.

Omor Ekushe scans the data/Layouts/ directory at application startup for any .xml layout definition file. Each layout is structured with root <Layout> and repeating <KeyMap> elements:

XML Schema Structure Specification 
<?xml version="1.0" encoding="utf-8"?>
<Layout name="YourLayoutName" author="YourName" version="1.0">
  <!-- virtual keycode vk="0x41" maps to hardware key 'A' -->
  <KeyMap vk="0x41">
    <Normal>া</Normal>   <!-- Character produced when typing 'A' -->
    <Shift>অ</Shift>    <!-- Character produced when typing Shift + 'A' -->
    <AltGr>্</AltGr>    <!-- Character produced when typing AltGr + 'A' -->
  </KeyMap>
</Layout>
Normal Tag

Defines the default character output without shift keys pressed.

Shift Tag

Defines character output when Shift modifier key is held down.

AltGr Tag

Defines optional third-tier character output for AltGr / Right-Alt combinations.
