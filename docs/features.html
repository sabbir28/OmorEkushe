Avro Phonetic Engine

C++17 Trie • F12 Toggle

Type Bengali phonetically using English QWERTY characters. Built with an optimized native C++ Trie grammar parser matching all Avro Phonetic typing standards:

  • Dynamic Diff Backspacing: Emits minimal backspaces to transform committed characters seamlessly (e.g. `k` → ক, `h` → খ).
  • Complex Conjuncts (যুক্তবর্ণ): Resolves clusters effortlessly (e.g. `kkh` → ক্ষ, `jng` → জ্ঞ, `nt` → ন্ত).
  • Vowel-to-Kar Transitions: Contextually decides full vowel vs. Kar diacritic based on preceding consonant.
  • Instant F12 Toggle: One-touch hotkey to jump between English and Phonetic typing in any app.

Kernel Low-Level Hook

WH_KEYBOARD_LL

Omor Ekushe intercepts hardware keyboard events directly at the Windows kernel message layer using SetWindowsHookExW(WH_KEYBOARD_LL, ...):

  • Zero input latency across all Win32, UWP, WPF, and Chromium web applications.
  • Clean passthrough for system hotkeys (Alt+Tab, Windows Key, Ctrl+C/V).
  • High-precision character translation with Unicode SendInput.

Per-Window Layout Memory

HWND Context Tracking

Never accidentally type Bengali in a terminal or English in a Bangla manuscript again:

  • Remembers layout mode (Bangla or English) independently for every window handle.
  • Restores your active layout state immediately upon window focus change.
  • Zero background CPU usage during idle state.

Custom XML Layout Map Syntax

Learn how to construct custom layout keymap files for Omor Ekushe.

Omor Ekushe scans the data/Layouts/ directory at application startup for any .xml layout definition file. Each layout is structured with root <Layout> and repeating <KeyMap> elements:

XML Schema Structure Specification 
<?xml version="1.0" encoding="utf-8"?>
<Layout name="YourLayoutName" author="YourName" version="1.0">
  <!-- virtual keycode vk="0x41" maps to hardware key 'A' -->
  <KeyMap vk="0x41">
    <Normal>া</Normal>   <!-- Character produced when typing 'A' -->
    <Shift>অ</Shift>    <!-- Character produced when typing Shift + 'A' -->
    <AltGr>্</AltGr>    <!-- Character produced when typing AltGr + 'A' -->
  </KeyMap>
</Layout>
Normal Tag

Defines the default character output without shift keys pressed.

Shift Tag

Defines character output when Shift modifier key is held down.

AltGr Tag

Defines optional third-tier character output for AltGr / Right-Alt combinations.
