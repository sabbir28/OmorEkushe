WHY OMOR EKUSHE?

Engineered for Performance & Customization

Everything you need for fluent Bengali desktop typing with minimal system impact.

Ultra-Lightweight Engine

Built from scratch in pure C++17 using Win32 API without heavy web engines (Electron/Qt). Launches instantly with ~5MB RAM usage.

Dynamic XML Layout Maps

Load layout definitions dynamically from simple XML files. Built-in support for Bijoy, Unijoy, National, and custom layout keymaps.

Per-Window Layout Memory

Automatically remembers active typing mode (Bangla or English) on a per-application window basis as you switch window focus.

Integrated Spelling Checker

Includes a dedicated `SpellingChecker` C++ core for real-time Bengali dictionary lookups and spell correction.

Graphical Layout Editor

Optional standalone sub-module `LayoutEditor` built with GLFW and Dear ImGui for visual creation and editing of keyboard layouts.

Acrylic Glassmorphism Bar

Sleek top bar control window with customizable opacity, background image support, and seamless system tray minimization.

CUSTOM LAYOUT FORMAT

Design Custom Keyboard Maps via XML

Omor Ekushe reads simple XML files in `data/`. Define virtual key mapping (`vk`), Normal, Shift, and AltGr character assignments effortlessly.

  • Standard virtual keycodes (`vk="0x41"` for 'A')
  • Supports Normal, Shift, and AltGr modifier states
  • Live reload layout without restarting application
Read XML Schema Guide
data/CustomBijoy.xml 
<?xml version="1.0" encoding="utf-8"?>
<Layout name="CustomBijoy" author="Sabbir" version="1.0">
  <KeyMap vk="0x41"> <!-- Virtual Key 'A' -->
    <Normal>া</Normal>
    <Shift>অ</Shift>
    <AltGr>্</AltGr>
  </KeyMap>
  <KeyMap vk="0x42"> <!-- Virtual Key 'B' -->
    <Normal>ন</Normal>
    <Shift>ণ</Shift>
  </KeyMap>
</Layout>
