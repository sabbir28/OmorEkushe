CORE CAPABILITIES

Engineered for Speed, Flexibility & Precision

A comprehensive Bengali keyboard solution combining modern phonetic convenience with classic layout support.

Avro Phonetic Engine

Type Bengali phonetically using standard English QWERTY characters. Features complex conjunct resolution, vowel-to-Kar transforms, dynamic diff backspacing, and an instant F12 toggle.

Options & Settings UI

Full native Win32 configuration dialog. Adjust overlay opacity (20%–100%) with real-time preview, toggle auto-start with Windows, and customize hotkey shortcuts without restarting.

Dynamic XML Layout Maps

Load layout definitions dynamically from XML files in data/Layouts/. Supports Bijoy Classic/Unicode, Unijoy, National, and unlimited custom user keymaps.

Per-Window Layout Memory

Omor Ekushe automatically tracks the active window handle (`HWND`) and restores the exact typing mode (Bangla or English) as you switch between your browser, IDE, Word, and chat apps.

Inno Setup CI Distribution

Zero local installer build complexity. Standard Inno Setup script compiled automatically by GitHub Actions CI. Supports seamless in-place updates, auto-closing running instances, and /VERYSILENT mode.

Kernel Low-Level Hook

Native WH_KEYBOARD_LL interceptor with SendInput Unicode injection ensures 0ms latency, bypasses IME overhead, and passes through critical system shortcuts like Alt+Tab and Win-key cleanly.

CUSTOM LAYOUT FORMAT

Design Custom Keyboard Maps via XML

Omor Ekushe reads simple XML files in data/Layouts/. Define virtual key mapping (vk), Normal, Shift, and AltGr character assignments effortlessly.

  • Standard virtual keycodes (vk="0x41" for 'A')
  • Supports Normal, Shift, and AltGr modifier states
  • Live reload layout without restarting application
Read XML Schema Guide
data/CustomBijoy.xml 
<?xml version="1.0" encoding="utf-8"?>
<Layout name="CustomBijoy" author="Sabbir" version="1.0">
  <KeyMap vk="0x41"> <!-- Virtual Key 'A' -->
    <Normal>া</Normal>
    <Shift>অ</Shift>
    <AltGr>্</AltGr>
  </KeyMap>
  <KeyMap vk="0x42"> <!-- Virtual Key 'B' -->
    <Normal>ন</Normal>
    <Shift>ণ</Shift>
  </KeyMap>
</Layout>
